# Lumina IA Studio

Sitio de **luminaiastudio.com** — la página de inscripción a la comunidad.

Este repositorio es **solo el sitio público**: la página y sus imágenes. Nada
del proyecto, del negocio ni de los clientes vive acá.

| Archivo | Qué es |
|---|---|
| `index.html` | La página completa |
| `luna/` | Las imágenes |
| `CNAME` | El dominio propio, para GitHub Pages |
